# Food Catching Basket Game

## About the game

An interactive Scratch game — control a basket and catch items falling from the sky.

- Catch a **food item** → +1 point
- Catch a **non-food item** → −1 point
- Reach **50 points within 1 minute** → you win.

## Controls

Move the basket left and right using mouse drag.

## How to play

1. Download `Picking up food in a basket(3).sb3` from this repository.
2. Open it in [Scratch](https://scratch.mit.edu/) — the free block-based coding platform made by MIT.
3. Click the green flag to start playing.
